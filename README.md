# Sistema de Integral de Gestión de Consultas Médicas (SIGCM)

## Descripción 

El Sistema de Integral de Gestión de Consultas Médicas (SIGCM) es proporcionar una herramienta eficiente para la gestión de consultas médicas en un centro médico.

## Objetivo General

Realizar una herramienta eficiente para la gestión de consultas médicas en un centro médico.

### Objetivos Específicos

- Gestionar los pacientes de un centro médico.
- Gestionar las consultas de un centro médico.
- Gestionar los médicos de un centro médico.
- Gestionar las citas de un centro médico.
- Gestionar las historias clínicas de un centro médico.


# Tecnologías

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: PostgreSQL
- Framework: Laravel
