# SIGCM — Sistema Integral de Gestión de Consultas Médicas

SIGCM es un sistema web para organizar la atención de un **centro médico**, desde el registro de pacientes y la programación de citas hasta la documentación de consultas e historias clínicas.

## Objetivo

Gestionar de forma consistente, segura y trazable la información operativa y clínica del centro médico.

## Alcance funcional (v1)

1. **Pacientes:** registro, identificación y consulta de datos.
2. **Médicos:** registro y administración de profesionales.
3. **Citas:** programación, confirmación y seguimiento de estados.
4. **Consultas médicas:** registro de la atención y evolución clínica.
5. **Historias clínicas:** antecedentes del paciente y acceso a sus consultas históricas.

**Distinción:** una cita es una reserva; una consulta es la atención efectivamente realizada; la historia clínica es el expediente longitudinal del paciente.

## Tecnologías utilizadas

| Capa / Componente | Tecnología | ¿Para qué sirve en SIGCM? |
|---|---|---|
| **Backend** | PHP 8.3 + Laravel 13 (`v13.42.0`) | Gestiona el enrutamiento web, migraciones, seeders, sesiones, pruebas automatizadas PHPUnit y la ejecución de consultas y procedimientos almacenados sobre PostgreSQL mediante PDO (`pgsql` y `pgsql_asistente`). |
| **Interfaz y Panel** | Filament 5 (`v5.11.4`) + Livewire 4 + Tailwind CSS 4 + Vite 8 | Construye el panel administrativo (`/admin`), el tablero ejecutivo en tiempo real y las 3 vistas iniciales (Catálogo Público, Historial de Citas/Consultas con modales transaccionales y Bitácora DCL) sin JavaScript manual complejo. |
| **Autorización RBAC** | Filament Shield 4 (`v4.3.1`) + Spatie Permission 8 (`v8.5.0`) | Administra roles y permisos de aplicación (`super_admin`, políticas de recursos y control de acceso al panel Filament) con `teams = false`. |
| **Base de datos** | PostgreSQL 17 (`db_sigcm`) | Motor relacional principal que garantiza integridad referencial y de dominio mediante claves primarias, `FOREIGN KEY` compuestas con `RESTRICT`, `UNIQUE`, `CHECK`, rangos `TIMESTAMPTZ` y bloqueos pesimistas (`FOR UPDATE`). |
| **Lógica en motor (BD II)** | PL/pgSQL (Índices, Triggers, Procedimientos, Cursor y Vistas) | Aplica reglas críticas directamente en la base de datos: impide modificar consultas firmadas, bloquea solapamientos de agenda, firma consultas y abre expedientes en transacciones atómicas, valoriza métricas con `CURSOR` y expone 3 vistas de lectura segura. |
| **Seguridad DCL y Auditoría** | Roles/Privilegios PostgreSQL (`rol_asistente_clinica`) + Bitácora nativa `audit_events` (`JSONB`) | Aplica el principio de mínimo privilegio (la sesión web `asistente_clinica_web` solo lee las 3 vistas públicas y recibe bloqueo `SQLSTATE 42501` sobre `audit_events`) mientras los triggers registran automáticamente eventos `INSERT`, `UPDATE`, `SIGN` y `AMEND` sin paquetes externos de auditoría. |

## Scripts SQL (PostgreSQL 17)

### Script 1 — Esquema relacional (`27` tablas) y registros iniciales (`270` inserts)


```sql
CREATE TABLE users (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(150) NOT NULL,
    email VARCHAR(255) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    email_verified_at TIMESTAMPTZ NULL,
    remember_token VARCHAR(100) NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE doctors (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id BIGINT NULL UNIQUE REFERENCES users(id) ON DELETE RESTRICT,
    first_names VARCHAR(150) NOT NULL,
    last_names VARCHAR(150) NOT NULL,
    professional_license VARCHAR(70) NOT NULL UNIQUE,
    specialty VARCHAR(150) NULL,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE patients (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    first_names VARCHAR(150) NOT NULL,
    last_names VARCHAR(150) NOT NULL,
    document_type VARCHAR(20) NULL,
    document_number VARCHAR(60) NULL,
    birth_date DATE NULL,
    phone VARCHAR(40) NULL,
    email VARCHAR(255) NULL,
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT uq_patient_document UNIQUE(document_type, document_number),
    CONSTRAINT ck_patient_document_pair CHECK ((document_type IS NULL) = (document_number IS NULL))
);

CREATE TABLE appointments (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL REFERENCES patients(id) ON DELETE RESTRICT,
    doctor_id BIGINT NOT NULL REFERENCES doctors(id) ON DELETE RESTRICT,
    created_by_user_id BIGINT NULL REFERENCES users(id) ON DELETE RESTRICT,
    starts_at TIMESTAMPTZ NOT NULL,
    ends_at TIMESTAMPTZ NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'pending',
    reason TEXT NULL,
    cancellation_reason TEXT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT uq_appointment_patient_doctor UNIQUE(id, patient_id, doctor_id),
    CONSTRAINT ck_appointment_interval CHECK(ends_at > starts_at),
    CONSTRAINT ck_appointment_status CHECK(status IN ('pending','confirmed','checked_in','completed','cancelled','no_show'))
);

CREATE TABLE appointment_reschedules (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    appointment_id BIGINT NOT NULL REFERENCES appointments(id) ON DELETE RESTRICT,
    changed_by_user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT,
    previous_start TIMESTAMPTZ NOT NULL,
    previous_end TIMESTAMPTZ NOT NULL,
    new_start TIMESTAMPTZ NOT NULL,
    new_end TIMESTAMPTZ NOT NULL,
    reason TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_reschedule_previous CHECK(previous_end > previous_start),
    CONSTRAINT ck_reschedule_new CHECK(new_end > new_start),
    CONSTRAINT ck_reschedule_changed CHECK(previous_start <> new_start OR previous_end <> new_end)
);

CREATE TABLE medical_consultations (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL REFERENCES patients(id) ON DELETE RESTRICT,
    doctor_id BIGINT NOT NULL REFERENCES doctors(id) ON DELETE RESTRICT,
    appointment_id BIGINT NULL UNIQUE,
    occurred_at TIMESTAMPTZ NOT NULL,
    status VARCHAR(15) NOT NULL DEFAULT 'draft',
    chief_complaint TEXT NULL,
    subjective TEXT NULL,
    objective TEXT NULL,
    assessment TEXT NULL,
    plan TEXT NULL,
    signed_at TIMESTAMPTZ NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT uq_consultation_patient UNIQUE(id, patient_id),
    CONSTRAINT fk_consultation_appointment_match FOREIGN KEY(appointment_id, patient_id, doctor_id)
        REFERENCES appointments(id, patient_id, doctor_id) ON DELETE RESTRICT,
    CONSTRAINT ck_consultation_status CHECK(status IN ('draft','signed')),
    CONSTRAINT ck_consultation_signature CHECK(
       (status='draft' AND signed_at IS NULL)
       OR (status='signed' AND signed_at IS NOT NULL AND chief_complaint IS NOT NULL)
    ),
    CONSTRAINT ck_consultation_signed_later CHECK(signed_at IS NULL OR signed_at >= occurred_at)
);

CREATE TABLE clinical_records (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL UNIQUE REFERENCES patients(id) ON DELETE RESTRICT,
    opened_from_consultation_id BIGINT NOT NULL UNIQUE,
    opened_at TIMESTAMPTZ NOT NULL,
    medical_history TEXT NULL,
    surgical_history TEXT NULL,
    family_history TEXT NULL,
    social_history TEXT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_record_opening_patient_match FOREIGN KEY(opened_from_consultation_id, patient_id)
        REFERENCES medical_consultations(id, patient_id) ON DELETE RESTRICT
);

CREATE TABLE care_episodes (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    clinical_record_id BIGINT NOT NULL REFERENCES clinical_records(id) ON DELETE RESTRICT,
    opening_consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    title VARCHAR(180) NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    opened_at TIMESTAMPTZ NOT NULL,
    closed_at TIMESTAMPTZ NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_episode_status CHECK(status IN ('active','resolved','suspended')),
    CONSTRAINT ck_episode_closed_after_open CHECK(closed_at IS NULL OR closed_at >= opened_at)
);

CREATE TABLE episode_consultations (
    episode_id BIGINT NOT NULL REFERENCES care_episodes(id) ON DELETE RESTRICT,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    relation_type VARCHAR(20) NOT NULL DEFAULT 'related',
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY(episode_id, consultation_id),
    CONSTRAINT ck_episode_consultation_relation CHECK(relation_type IN ('initial','follow_up','related'))
);

CREATE TABLE follow_up_plans (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    originating_consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    episode_id BIGINT NULL REFERENCES care_episodes(id) ON DELETE RESTRICT,
    appointment_id BIGINT NULL REFERENCES appointments(id) ON DELETE RESTRICT,
    resulting_consultation_id BIGINT NULL UNIQUE REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    due_at TIMESTAMPTZ NULL,
    goal TEXT NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'pending',
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_followup_status CHECK(status IN ('pending','scheduled','completed','cancelled','missed')),
    CONSTRAINT ck_followup_result CHECK(resulting_consultation_id IS NULL OR status = 'completed')
);

CREATE TABLE patient_conditions (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL REFERENCES patients(id) ON DELETE RESTRICT,
    code_system VARCHAR(70) NULL,
    code VARCHAR(70) NULL,
    display VARCHAR(255) NOT NULL,
    clinical_status VARCHAR(20) NOT NULL DEFAULT 'active',
    verification_status VARCHAR(20) NOT NULL DEFAULT 'unconfirmed',
    onset_date DATE NULL,
    resolved_date DATE NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_condition_status CHECK(clinical_status IN ('active','resolved','inactive')),
    CONSTRAINT ck_condition_verification CHECK(verification_status IN ('unconfirmed','confirmed','refuted')),
    CONSTRAINT ck_condition_dates CHECK(onset_date IS NULL OR resolved_date IS NULL OR resolved_date >= onset_date)
);

CREATE TABLE patient_allergies (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL REFERENCES patients(id) ON DELETE RESTRICT,
    substance VARCHAR(180) NOT NULL,
    reaction VARCHAR(180) NULL,
    severity VARCHAR(15) NULL,
    verification_status VARCHAR(20) NOT NULL DEFAULT 'unconfirmed',
    clinical_status VARCHAR(20) NOT NULL DEFAULT 'active',
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_allergy_severity CHECK(severity IS NULL OR severity IN ('mild','moderate','severe')),
    CONSTRAINT ck_allergy_verification CHECK(verification_status IN ('unconfirmed','confirmed','refuted')),
    CONSTRAINT ck_allergy_status CHECK(clinical_status IN ('active','inactive','resolved'))
);

CREATE TABLE patient_medications (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL REFERENCES patients(id) ON DELETE RESTRICT,
    medication_name VARCHAR(180) NOT NULL,
    dose VARCHAR(100) NULL,
    frequency VARCHAR(100) NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    source VARCHAR(30) NOT NULL DEFAULT 'patient_report',
    recorded_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_patient_medication_status CHECK(status IN ('active','stopped','unknown')),
    CONSTRAINT ck_patient_medication_source CHECK(source IN ('patient_report','external_prescription','internal_reconciliation'))
);

CREATE TABLE episode_conditions (
    episode_id BIGINT NOT NULL REFERENCES care_episodes(id) ON DELETE RESTRICT,
    condition_id BIGINT NOT NULL REFERENCES patient_conditions(id) ON DELETE RESTRICT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY(episode_id, condition_id)
);

CREATE TABLE consultation_diagnoses (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    patient_condition_id BIGINT NULL REFERENCES patient_conditions(id) ON DELETE RESTRICT,
    code_system VARCHAR(70) NULL,
    code VARCHAR(70) NULL,
    diagnosis_text VARCHAR(255) NOT NULL,
    certainty VARCHAR(20) NOT NULL DEFAULT 'suspected',
    is_primary BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_diagnosis_certainty CHECK(certainty IN ('suspected','confirmed','ruled_out'))
);

CREATE TABLE clinical_observations (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    code VARCHAR(70) NOT NULL,
    value_number NUMERIC(12,3) NULL,
    value_text VARCHAR(255) NULL,
    unit_code VARCHAR(32) NULL,
    observed_at TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_observation_has_one_value CHECK((value_number IS NOT NULL) <> (value_text IS NOT NULL))
);

CREATE TABLE prescriptions (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    supersedes_prescription_id BIGINT NULL REFERENCES prescriptions(id) ON DELETE RESTRICT,
    status VARCHAR(20) NOT NULL DEFAULT 'draft',
    issued_at TIMESTAMPTZ NULL,
    notes TEXT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_prescription_status CHECK(status IN ('draft','issued','replaced','void')),
    CONSTRAINT ck_prescription_issued CHECK(status = 'draft' OR issued_at IS NOT NULL),
    CONSTRAINT ck_prescription_no_self_supersede CHECK(supersedes_prescription_id IS NULL OR supersedes_prescription_id <> id)
);

CREATE TABLE prescription_items (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    prescription_id BIGINT NOT NULL REFERENCES prescriptions(id) ON DELETE RESTRICT,
    medication_name VARCHAR(180) NOT NULL,
    dose VARCHAR(100) NOT NULL,
    route VARCHAR(100) NOT NULL,
    frequency VARCHAR(100) NOT NULL,
    duration_days INTEGER NULL,
    quantity NUMERIC(12,2) NULL,
    instructions TEXT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_prescription_duration CHECK(duration_days IS NULL OR duration_days > 0),
    CONSTRAINT ck_prescription_quantity CHECK(quantity IS NULL OR quantity > 0)
);

CREATE TABLE clinical_orders (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    order_type VARCHAR(20) NOT NULL,
    title VARCHAR(180) NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'ordered',
    priority VARCHAR(20) NOT NULL DEFAULT 'routine',
    ordered_at TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_order_type CHECK(order_type IN ('lab','imaging','procedure','other')),
    CONSTRAINT ck_order_status CHECK(status IN ('ordered','completed','cancelled')),
    CONSTRAINT ck_order_priority CHECK(priority IN ('routine','urgent'))
);

CREATE TABLE diagnostic_reports (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    clinical_order_id BIGINT NOT NULL REFERENCES clinical_orders(id) ON DELETE RESTRICT,
    reviewed_by_user_id BIGINT NULL REFERENCES users(id) ON DELETE RESTRICT,
    status VARCHAR(20) NOT NULL DEFAULT 'received',
    interpretation TEXT NULL,
    issued_at TIMESTAMPTZ NULL,
    reviewed_at TIMESTAMPTZ NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_report_status CHECK(status IN ('received','reviewed','amended')),
    CONSTRAINT ck_report_review CHECK(
       (status='received' AND reviewed_at IS NULL AND reviewed_by_user_id IS NULL)
       OR (status IN ('reviewed','amended') AND reviewed_at IS NOT NULL AND reviewed_by_user_id IS NOT NULL)
    )
);

CREATE TABLE diagnostic_result_items (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    diagnostic_report_id BIGINT NOT NULL REFERENCES diagnostic_reports(id) ON DELETE RESTRICT,
    test_code VARCHAR(70) NULL,
    test_name VARCHAR(180) NOT NULL,
    result_number NUMERIC(12,3) NULL,
    result_text VARCHAR(255) NULL,
    unit_code VARCHAR(32) NULL,
    reference_range VARCHAR(100) NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_result_value CHECK((result_number IS NOT NULL) <> (result_text IS NOT NULL))
);

CREATE TABLE referrals (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    specialty_or_service VARCHAR(180) NOT NULL,
    reason TEXT NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'requested',
    requested_at TIMESTAMPTZ NOT NULL,
    CONSTRAINT ck_referral_status CHECK(status IN ('requested','accepted','completed','cancelled'))
);

CREATE TABLE clinical_documents (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    patient_id BIGINT NOT NULL REFERENCES patients(id) ON DELETE RESTRICT,
    consultation_id BIGINT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    uploaded_by_user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT,
    document_type VARCHAR(60) NOT NULL,
    storage_path VARCHAR(500) NOT NULL,
    mime_type VARCHAR(120) NOT NULL,
    uploaded_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE care_plans (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    episode_id BIGINT NOT NULL REFERENCES care_episodes(id) ON DELETE RESTRICT,
    created_from_consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    objective TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_care_plan_status CHECK(status IN ('active','completed','cancelled'))
);

CREATE TABLE care_plan_activities (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    care_plan_id BIGINT NOT NULL REFERENCES care_plans(id) ON DELETE RESTRICT,
    description TEXT NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'pending',
    due_at TIMESTAMPTZ NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_care_activity_status CHECK(status IN ('pending','done','cancelled'))
);

CREATE TABLE consultation_amendments (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    consultation_id BIGINT NOT NULL REFERENCES medical_consultations(id) ON DELETE RESTRICT,
    author_user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT,
    reason TEXT NOT NULL,
    additional_note TEXT NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE audit_events (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    actor_user_id BIGINT NULL REFERENCES users(id) ON DELETE RESTRICT,
    entity_name VARCHAR(100) NOT NULL,
    entity_id BIGINT NOT NULL,
    operation VARCHAR(12) NOT NULL,
    changed_fields JSONB NOT NULL DEFAULT '{}'::jsonb,
    occurred_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_audit_operation CHECK(operation IN ('INSERT','UPDATE','DELETE','SIGN','AMEND')),
    CONSTRAINT ck_audit_metadata_object CHECK(jsonb_typeof(changed_fields) = 'object')
);
```

```sql
-- 2.1 Inmutabilidad de consultas médicas firmadas
CREATE OR REPLACE FUNCTION fn_validar_inmutabilidad_consulta()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
BEGIN
    IF TG_OP = 'DELETE' THEN
        IF OLD.status = 'signed' THEN
            RAISE EXCEPTION 'Error de integridad clínica: No se puede eliminar la consulta ID % porque ya está firmada.', OLD.id;
        END IF;
        RETURN OLD;
    END IF;

    IF TG_OP = 'UPDATE' THEN
        IF OLD.status = 'signed' THEN
            RAISE EXCEPTION 'Error de integridad clínica: La consulta ID % ya está firmada y es inmutable. Registre una enmienda en consultation_amendments.', OLD.id;
        END IF;

        IF NEW.status = 'signed' AND COALESCE(btrim(NEW.chief_complaint), '') = '' THEN
            RAISE EXCEPTION 'Error de integridad clínica: El motivo de consulta (chief_complaint) es obligatorio para firmar.';
        END IF;
    END IF;

    RETURN NEW;
END;
$$;

DROP TRIGGER IF EXISTS trg_validar_inmutabilidad_consulta ON medical_consultations;

CREATE TRIGGER trg_validar_inmutabilidad_consulta
BEFORE UPDATE OR DELETE ON medical_consultations
FOR EACH ROW
EXECUTE FUNCTION fn_validar_inmutabilidad_consulta();

-- 2.2 Bloqueo de solapamiento de citas activas por médico
CREATE OR REPLACE FUNCTION fn_validar_solapamiento_cita()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
BEGIN
    IF NEW.status IN ('pending', 'confirmed', 'checked_in') THEN
        IF EXISTS (
            SELECT 1
            FROM appointments a
            WHERE a.doctor_id = NEW.doctor_id
              AND a.id <> COALESCE(NEW.id, -1)
              AND a.status IN ('pending', 'confirmed', 'checked_in')
              AND tstzrange(a.starts_at, a.ends_at, '[)') && tstzrange(NEW.starts_at, NEW.ends_at, '[)')
        ) THEN
            RAISE EXCEPTION 'Error de integridad en agenda: El médico ID % ya posee una cita activa en ese horario.', NEW.doctor_id;
        END IF;
    END IF;

    RETURN NEW;
END;
$$;

DROP TRIGGER IF EXISTS trg_validar_solapamiento_cita ON appointments;

CREATE TRIGGER trg_validar_solapamiento_cita
BEFORE INSERT OR UPDATE ON appointments
FOR EACH ROW
EXECUTE FUNCTION fn_validar_solapamiento_cita();

-- 2.3 Auditoría automática de consultas médicas hacia audit_events
CREATE OR REPLACE FUNCTION fn_auditoria_consultas()
RETURNS TRIGGER
LANGUAGE plpgsql
AS $$
DECLARE
    v_actor_user_id BIGINT;
    v_operation VARCHAR(12);
BEGIN
    v_actor_user_id := NULLIF(current_setting('app.current_user_id', true), '')::BIGINT;

    IF v_actor_user_id IS NULL THEN
        SELECT d.user_id
        INTO v_actor_user_id
        FROM doctors d
        WHERE d.id = NEW.doctor_id;
    END IF;

    IF TG_OP = 'INSERT' THEN
        v_operation := CASE WHEN NEW.status = 'signed' THEN 'SIGN' ELSE 'INSERT' END;
        INSERT INTO audit_events (actor_user_id, entity_name, entity_id, operation, changed_fields, occurred_at)
        VALUES (
            v_actor_user_id,
            'medical_consultations',
            NEW.id,
            v_operation,
            jsonb_build_object(
                'new_status', NEW.status,
                'patient_id', NEW.patient_id,
                'doctor_id', NEW.doctor_id,
                'db_user', CURRENT_USER
            ),
            CURRENT_TIMESTAMP
        );
    ELSIF TG_OP = 'UPDATE' THEN
        IF OLD.status IS DISTINCT FROM NEW.status
           OR OLD.signed_at IS DISTINCT FROM NEW.signed_at
           OR OLD.chief_complaint IS DISTINCT FROM NEW.chief_complaint THEN
            v_operation := CASE
                WHEN OLD.status <> 'signed' AND NEW.status = 'signed' THEN 'SIGN'
                ELSE 'UPDATE'
            END;

            INSERT INTO audit_events (actor_user_id, entity_name, entity_id, operation, changed_fields, occurred_at)
            VALUES (
                v_actor_user_id,
                'medical_consultations',
                NEW.id,
                v_operation,
                jsonb_build_object(
                    'previous_status', OLD.status,
                    'new_status', NEW.status,
                    'signed_at', NEW.signed_at,
                    'db_user', CURRENT_USER
                ),
                CURRENT_TIMESTAMP
            );
        END IF;
    END IF;

    RETURN NEW;
END;
$$;

AFTER INSERT OR UPDATE ON medical_consultations

-- 3. PROCEDIMIENTOS ALMACENADOS TRANSACCIONALES Y CURSOR (PL/pgSQL)

-- 3.1 Registro atómico y firma de consulta + apertura de historia clínica y episodio
DROP PROCEDURE IF EXISTS sp_registrar_y_firmar_consulta_segura(
    BIGINT, BIGINT, BIGINT, TEXT, TEXT, TEXT, TEXT, TEXT, VARCHAR, BIGINT
);

CREATE PROCEDURE sp_registrar_y_firmar_consulta_segura(
    IN p_patient_id BIGINT,
    IN p_doctor_id BIGINT,
    IN p_appointment_id BIGINT,
    IN p_chief_complaint TEXT,
    IN p_subjective TEXT,
    IN p_objective TEXT,
    IN p_assessment TEXT,
    IN p_plan TEXT,
    IN p_episode_title VARCHAR(180),
    IN p_actor_user_id BIGINT DEFAULT NULL
)
LANGUAGE plpgsql
AS $$
DECLARE
    v_patient_id BIGINT;
    v_doctor_id BIGINT;
    v_appt_patient_id BIGINT;
    v_appt_doctor_id BIGINT;
    v_appt_status VARCHAR(20);
    v_occurred_at TIMESTAMPTZ;
    v_signed_at TIMESTAMPTZ;
    v_consultation_id BIGINT;
    v_clinical_record_id BIGINT;
    v_episode_id BIGINT;
    v_effective_title VARCHAR(180);
BEGIN
    IF p_actor_user_id IS NOT NULL THEN
        PERFORM set_config('app.current_user_id', p_actor_user_id::text, true);
    END IF;

    IF COALESCE(btrim(p_chief_complaint), '') = '' THEN
        RAISE EXCEPTION 'El motivo de consulta es obligatorio para firmar.';
    END IF;

    -- Bloqueo pesimista del paciente para evitar apertura concurrente duplicada de historia
    SELECT id INTO v_patient_id
    FROM patients
    WHERE id = p_patient_id AND is_active = TRUE
    FOR UPDATE;

    IF NOT FOUND THEN
        RAISE EXCEPTION 'El paciente ID % no existe o está inactivo.', p_patient_id;
    END IF;

    SELECT id INTO v_doctor_id
    FROM doctors
    WHERE id = p_doctor_id AND is_active = TRUE;

    IF NOT FOUND THEN
        RAISE EXCEPTION 'El médico ID % no existe o está inactivo.', p_doctor_id;
    END IF;

    IF p_appointment_id IS NOT NULL THEN
        SELECT patient_id, doctor_id, status
        INTO v_appt_patient_id, v_appt_doctor_id, v_appt_status
        FROM appointments
        WHERE id = p_appointment_id
        FOR UPDATE;

        IF NOT FOUND THEN
            RAISE EXCEPTION 'La cita ID % no existe.', p_appointment_id;
        END IF;

        IF v_appt_patient_id <> p_patient_id OR v_appt_doctor_id <> p_doctor_id THEN
            RAISE EXCEPTION 'La cita ID % no corresponde al paciente y médico seleccionados.', p_appointment_id;
        END IF;

        IF v_appt_status IN ('cancelled', 'no_show') THEN
            RAISE EXCEPTION 'No se puede registrar una consulta sobre una cita en estado %.', v_appt_status;
        END IF;
    END IF;

    v_occurred_at := clock_timestamp();

    INSERT INTO medical_consultations (
        patient_id,
        doctor_id,
        appointment_id,
        occurred_at,
        status,
        chief_complaint,
        subjective,
        objective,
        assessment,
        plan,
        created_at,
        updated_at
    )
    VALUES (
        p_patient_id,
        p_doctor_id,
        p_appointment_id,
        v_occurred_at,
        'draft',
        btrim(p_chief_complaint),
        NULLIF(btrim(COALESCE(p_subjective, '')), ''),
        NULLIF(btrim(COALESCE(p_objective, '')), ''),
        NULLIF(btrim(COALESCE(p_assessment, '')), ''),
        NULLIF(btrim(COALESCE(p_plan, '')), ''),
        v_occurred_at,
        v_occurred_at
    )
    RETURNING id INTO v_consultation_id;

    v_signed_at := clock_timestamp();
    IF v_signed_at < v_occurred_at THEN
        v_signed_at := v_occurred_at;
    END IF;

    UPDATE medical_consultations
    SET status = 'signed',
        signed_at = v_signed_at,
        updated_at = v_signed_at
    WHERE id = v_consultation_id;

    -- Abrir historia clínica longitudinal si el paciente aún no tiene una
    SELECT id INTO v_clinical_record_id
    FROM clinical_records
    WHERE patient_id = p_patient_id
    FOR UPDATE;

    IF NOT FOUND THEN
        INSERT INTO clinical_records (
            patient_id,
            opened_from_consultation_id,
            opened_at,
            created_at,
            updated_at
        )
        VALUES (
            p_patient_id,
            v_consultation_id,
            v_signed_at,
            v_signed_at,
            v_signed_at
        )
        RETURNING id INTO v_clinical_record_id;
    END IF;

    v_effective_title := COALESCE(NULLIF(btrim(COALESCE(p_episode_title, '')), ''), 'Episodio clínico ambulatorio');

    INSERT INTO care_episodes (
        clinical_record_id,
        opening_consultation_id,
        title,
        status,
        opened_at,
        created_at,
        updated_at
    )
    VALUES (
        v_clinical_record_id,
        v_consultation_id,
        v_effective_title,
        'active',
        v_signed_at,
        v_signed_at,
        v_signed_at
    )
    RETURNING id INTO v_episode_id;

    INSERT INTO episode_consultations (
        episode_id,
        consultation_id,
        relation_type,
        created_at
    )
    VALUES (
        v_episode_id,
        v_consultation_id,
        'initial',
        v_signed_at
    );

    IF p_appointment_id IS NOT NULL THEN
        UPDATE appointments
        SET status = 'completed',
            updated_at = v_signed_at
        WHERE id = p_appointment_id;
    END IF;

    RAISE NOTICE 'Consulta ID % firmada, historia clínica ID % asegurada y episodio ID % creado.',
        v_consultation_id, v_clinical_record_id, v_episode_id;

EXCEPTION
    WHEN OTHERS THEN
        RAISE EXCEPTION 'Error crítico: transacción clínica revertida. Detalle: %', SQLERRM;
END;
$$;

-- 3.2 Reprogramación segura de cita con bloqueo FOR UPDATE y detección de solapamiento
DROP PROCEDURE IF EXISTS sp_reprogramar_cita_segura(
    BIGINT, BIGINT, TIMESTAMPTZ, TIMESTAMPTZ, TEXT
);

CREATE PROCEDURE sp_reprogramar_cita_segura(
    IN p_appointment_id BIGINT,
    IN p_changed_by_user_id BIGINT,
    IN p_new_start TIMESTAMPTZ,
    IN p_new_end TIMESTAMPTZ,
    IN p_reason TEXT
)
LANGUAGE plpgsql
AS $$
DECLARE
    v_prev_start TIMESTAMPTZ;
    v_prev_end TIMESTAMPTZ;
    v_status VARCHAR(20);
BEGIN
    IF p_changed_by_user_id IS NOT NULL THEN
        PERFORM set_config('app.current_user_id', p_changed_by_user_id::text, true);
    END IF;

    IF p_new_end <= p_new_start THEN
        RAISE EXCEPTION 'La fecha de fin debe ser posterior a la fecha de inicio.';
    END IF;

    IF COALESCE(btrim(p_reason), '') = '' THEN
        RAISE EXCEPTION 'El motivo de reprogramación es obligatorio.';
    END IF;

    SELECT starts_at, ends_at, status
    INTO v_prev_start, v_prev_end, v_status
    FROM appointments
    WHERE id = p_appointment_id
    FOR UPDATE;

    IF NOT FOUND THEN
        RAISE EXCEPTION 'La cita ID % no existe.', p_appointment_id;
    END IF;

    IF v_status IN ('completed', 'cancelled', 'no_show') THEN
        RAISE EXCEPTION 'No se puede reprogramar una cita en estado %.', v_status;
    END IF;

    IF v_prev_start = p_new_start AND v_prev_end = p_new_end THEN
        RAISE EXCEPTION 'El nuevo horario debe ser distinto al horario anterior.';
    END IF;

    INSERT INTO appointment_reschedules (
        appointment_id,
        changed_by_user_id,
        previous_start,
        previous_end,
        new_start,
        new_end,
        reason,
        created_at
    )
    VALUES (
        p_appointment_id,
        p_changed_by_user_id,
        v_prev_start,
        v_prev_end,
        p_new_start,
        p_new_end,
        btrim(p_reason),
        clock_timestamp()
    );

    UPDATE appointments
    SET starts_at = p_new_start,
        ends_at = p_new_end,
        updated_at = clock_timestamp()
    WHERE id = p_appointment_id;

    RAISE NOTICE 'Cita ID % reprogramada con éxito.', p_appointment_id;

EXCEPTION
    WHEN OTHERS THEN
        RAISE EXCEPTION 'Error crítico: reprogramación revertida. Detalle: %', SQLERRM;
END;
$$;

-- 3.3 Resumen ejecutivo mediante CURSOR explícito (réplica de sp_valorizar_inventario)
DROP PROCEDURE IF EXISTS sp_valorizar_actividad_clinica();
DROP PROCEDURE IF EXISTS sp_valorizar_actividad_clinica(OUT INT, OUT INT, OUT NUMERIC);

CREATE OR REPLACE PROCEDURE sp_valorizar_actividad_clinica(
    OUT p_total_consultas_firmadas INT,
    OUT p_total_citas_activas INT,
    OUT p_total_horas_agenda NUMERIC(10,2)
)
LANGUAGE plpgsql
AS $$
DECLARE
    v_status VARCHAR(20);
    v_horas NUMERIC(10,4);
    cur_agenda CURSOR FOR
        SELECT status, EXTRACT(EPOCH FROM (ends_at - starts_at)) / 3600.0
        FROM appointments;
BEGIN
    p_total_citas_activas := 0;
    p_total_horas_agenda := 0.00;

    SELECT COUNT(*)::INT
    INTO p_total_consultas_firmadas
    FROM medical_consultations
    WHERE status = 'signed';

    OPEN cur_agenda;
    LOOP
        FETCH cur_agenda INTO v_status, v_horas;
        EXIT WHEN NOT FOUND;

        IF v_status IN ('pending', 'confirmed', 'checked_in') THEN
            p_total_citas_activas := p_total_citas_activas + 1;
        END IF;

        IF v_status <> 'cancelled' THEN
            p_total_horas_agenda := p_total_horas_agenda + COALESCE(v_horas, 0);
        END IF;
    END LOOP;
    CLOSE cur_agenda;

    p_total_horas_agenda := ROUND(p_total_horas_agenda, 2);
END;
$$;

-- 4. VISTAS PÚBLICAS / CONSOLIDADAS (mínimo privilegio para capa web)

CREATE OR REPLACE VIEW vw_catalogo_medicos_publico AS
SELECT
    d.id AS doctor_id,
    d.professional_license,
    d.first_names || ' ' || d.last_names AS nombre_completo,
    COALESCE(d.specialty, 'Medicina general') AS specialty,
    d.is_active,
    COUNT(DISTINCT a.id)::INT AS total_citas,
    COUNT(DISTINCT CASE WHEN mc.status = 'signed' THEN mc.id END)::INT AS consultas_firmadas
FROM doctors d
LEFT JOIN appointments a ON a.doctor_id = d.id
LEFT JOIN medical_consultations mc ON mc.doctor_id = d.id
GROUP BY d.id, d.professional_license, d.first_names, d.last_names, d.specialty, d.is_active;

CREATE OR REPLACE VIEW vw_agenda_consultas_detalle AS
SELECT
    a.id AS appointment_id,
    'CITA-' || lpad(a.id::text, 4, '0') AS codigo_cita,
    p.id AS patient_id,
    p.first_names || ' ' || p.last_names AS paciente,
    COALESCE(p.document_type || '-' || p.document_number, 'Sin documento') AS documento_paciente,
    d.id AS doctor_id,
    d.first_names || ' ' || d.last_names AS medico,
    COALESCE(d.specialty, 'Medicina general') AS especialidad,
    a.starts_at,
    a.ends_at,
    a.status AS estado_cita,
    mc.id AS consultation_id,
    COALESCE(mc.status, 'sin_consulta') AS estado_consulta,
    mc.signed_at,
    (cr.id IS NOT NULL) AS tiene_expediente
FROM appointments a
INNER JOIN patients p ON p.id = a.patient_id
INNER JOIN doctors d ON d.id = a.doctor_id
LEFT JOIN medical_consultations mc ON mc.appointment_id = a.id
LEFT JOIN clinical_records cr ON cr.patient_id = p.id;

CREATE OR REPLACE VIEW vw_expedientes_episodios_resumen AS
SELECT
    cr.id AS clinical_record_id,
    'HC-' || lpad(cr.id::text, 4, '0') AS codigo_historia,
    p.id AS patient_id,
    p.first_names || ' ' || p.last_names AS paciente,
    COALESCE(p.document_type || '-' || p.document_number, 'Sin documento') AS documento_paciente,
    cr.opened_at,
    mc.id AS consultation_apertura_id,
    mc.status AS estado_consulta_apertura,
    COUNT(DISTINCT ce.id)::INT AS total_episodios,
    COUNT(DISTINCT fup.id)::INT AS seguimientos_pendientes
FROM clinical_records cr
INNER JOIN patients p ON p.id = cr.patient_id
INNER JOIN medical_consultations mc ON mc.id = cr.opened_from_consultation_id
LEFT JOIN care_episodes ce ON ce.clinical_record_id = cr.id
LEFT JOIN follow_up_plans fup ON fup.episode_id = ce.id AND fup.status = 'pending'
GROUP BY cr.id, p.id, p.first_names, p.last_names, p.document_type, p.document_number, cr.opened_at, mc.id, mc.status;
```
